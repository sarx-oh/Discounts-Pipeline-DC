# Declarative pipelines

This release does not deploy Lakeflow Declarative Pipelines. It uses a notebook Job, Delta tables and explicit quality controls. This template directory documents that decision; it does not represent a deployed declarative pipeline. The Phase 2 guide explicitly requests a Databricks job or workflow and evaluates the relevant use or consideration of the listed engineering technologies. The repository template’s example declarative configuration is not represented here as an implemented resource. See [technical decisions](../../docs/decisiones_tecnicas.md).
